VidChopper macOS trust guidance
===============================

The adjacent checksum proves that a downloaded file matches the qualified
release bytes. A checksum does not prove who built the file or that Apple
notarized it.

Signing
-------
The release uses ad-hoc signing. It is not Developer ID signed and is not
notarized. macOS can therefore show an unidentified-developer or first-open
warning for a browser-downloaded copy.

Before opening
--------------
1. Confirm the DMG checksum using the adjacent .sha256 file.
2. Confirm that the DMG came from the official VidChopper GitHub release.
3. Inspect the package contents and the included notices.
4. If macOS asks for approval, use the normal Finder/System Settings flow only
   after you have independently decided to trust this artifact.

VidChopper does not disable Gatekeeper, remove com.apple.quarantine, register
a global exception with spctl, or use another quarantine bypass. If the
provenance or checksum is unexpected, do not open the package.

Runtime tools
-------------
ffmpeg and ffprobe are intentionally outside this package. Treat separately
installed media tools as separate software with separate trust and licensing
decisions.
