VidChopper 0.3.0-beta is the first beta release and the first portable package to include the complete Qt-free command-line workflow beside the Qt desktop application.

## Highlights

- Adds `VidChopperCLI.exe` with direct and `chop` invocation modes.
- Accepts explicit JSON or YAML ChapterFiles and explicitly selected embedded chapters.
- Adds safe dry-run planning, batch resolution, deterministic output naming, and settings precedence.
- Exports clips through ffmpeg with progress summaries and JSON/CSV manifests.
- Preserves actionable probing, process, export, and manifest failures.
- Verifies a game-neutral ChapterBuilder export from the public TNS 2XKO #36 fixture.
- Adds repository-owned Quick, Full, and Release verification tiers plus clean Windows archive smoke testing.

## Package

The Windows x64 ZIP contains both `VidChopper.exe` and `VidChopperCLI.exe`, the Qt runtime required by the GUI, the Microsoft Visual C++ runtime, `yaml-cpp.dll`, notices, and the project license.

The release also publishes an adjacent `.sha256` file for independent package verification.

`ffmpeg` and `ffprobe` are intentionally not bundled. Install them separately and keep them on `PATH`, or configure their locations in the desktop application's Advanced Settings.

The canonical documentation route is staged at https://vidchopper.app/docs and becomes authoritative
after the production rollout is live-validated. Until then, use the repository documentation.

This is a beta prerelease. Please report reproducible problems through the GitHub repository.
