VidChopper 1.2.0 is the first supported Apple Silicon macOS release and remains a cumulative Windows release.

## Downloads

- Windows 10/11 x64: download `VidChopper-1.2.0-windows-x64.zip`, verify its adjacent checksum, extract it, and run `VidChopper.exe` or `VidChopperCLI.exe`.
- macOS 15 or newer on Apple Silicon: download `VidChopper-1.2.0-macos-arm64.dmg`, verify its adjacent checksum, and drag `VidChopper.app` to Applications.
- Standalone Mac CLI: download `VidChopper-1.2.0-macos-arm64-cli.tar.gz`, verify its adjacent checksum, extract it, and run `Install CLI.command` for a no-`sudo` user-local install.

FFmpeg and ffprobe remain external dependencies on both platforms and are never bundled or downloaded by VidChopper.

## macOS trust model

The macOS app and CLI are ad-hoc signed. They are not Developer ID signed or notarized. A browser download may therefore be quarantined on first launch. Use the documented per-app approval flow in System Settings; do not disable Gatekeeper globally and do not remove quarantine metadata as an installation shortcut.

## Highlights

- Native Apple Silicon GUI and standalone CLI packages for macOS 15 and newer.
- HEVC VideoToolbox capability detection and automatic selection on supported Apple Silicon Macs, with x264 fallback when automatic hardware probing fails.
- Native macOS settings under `~/Library/Application Support/VidChopper/`, with explicit and portable overrides.
- Exact-candidate checksum, signature, dependency, relocated-launch, dry-run, export, manifest, and physical-Mac gates.
- Requalified Windows 10/11 x64 GUI and CLI from the same source commit.

Linux remains source- and CI-compatible, but 1.2.0 does not publish or support an end-user Linux package. Linux packaging is planned for 1.3.0.

See the repository support matrix and macOS installation guide for the supported boundary and first-launch steps.
