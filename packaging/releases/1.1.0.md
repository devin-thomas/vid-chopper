VidChopper 1.1.0 is the shared Unix foundation release. The Windows desktop app and command-line tool
are the only end-user binaries; the shared core, CLI, process, path, configuration, tool-discovery,
encoder, and Qt boundaries are qualified across the source/CI platforms.

## Published boundary

The published Windows 10/11 x64 portable ZIP contains:

- `VidChopper.exe` and `VidChopperCLI.exe`;
- the Qt runtime, Microsoft Visual C++ runtime, and `yaml-cpp.dll`;
- the license, third-party notices, and offline CLI agent skill.

FFmpeg and ffprobe remain external dependencies and are never bundled. macOS and Linux are source/CI
evidence only in 1.1.0: no public Unix package or end-user support claim is made until 1.2.0 and 1.3.0.

## Qualification evidence

The exact published candidate passed the core, slow FFmpeg, Qt, clean extracted-archive,
Unicode/spaced-path, settings-compatibility, tool-validation, encoder, manifest, and cancellation checks.
The adjacent `VidChopper-1.1.0-windows-x64.zip.sha256` file is the authoritative checksum for the
published package. The source commit, hash, dependency versions, and lane outcomes are recorded in
`docs/1.1.0-foundation-evidence.md`.

## Known limitations

- Exports remain sequential.
- macOS and Linux GUI builds are compile/launch evidence, not published support.
- FFmpeg/ffprobe installation and trust decisions remain the user's responsibility.
